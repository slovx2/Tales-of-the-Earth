# 古地形数据验证与推演可行性

## 1. 范围与结论

本轮只回答三个问题：是否存在可直接使用的全球古地形数据、它与当前 MULLER2022 海陆几何是否匹配、若不能直接使用能否基于公开方法自行推演。

结论：

- 已确认可公开下载的全球古地形/古海深数据为 **PALEOMAP PaleoDEM**。它覆盖 `0–540 Ma`，高分辨率包为 `0.1°` 网格、每 `5 Ma` 一片、CC BY 4.0。
- 实测证明 PaleoDEM 不能直接与当前 MULLER2022 古海岸线叠加。0 Ma 尚能匹配，但 100 Ma 以后存在明显的板块位置、绝对参考系和海岸线定义差异。
- 当前没有找到可直接下载、同时覆盖 `0–1000 Ma`、又原生基于当前 MULLER2022 的全球高程数据。
- Merdith 等人在 2025 年公开了一套 `1 Ga–0 Ma` 的参数化推演方法。方法与本项目所用全板块模型高度相容，但公开页面目前只有预印本 PDF，没有论文所称的补充代码和输出数据。
- 因此，PaleoDEM 暂时只能作为独立参考和视觉标尺，不能成为运行时逐像素高度来源。正式路线应优先获取 Merdith 2025 的补充材料；若仍不可得，再在当前 MULLER2022 上复现其方法。

本阶段不修改 Unity 渲染，不做几何高度夸张。

## 3. PALEOMAP PaleoDEM 实测

### 3.1 来源与文件

来源记录：

- 标题：PALEOMAP Paleodigital Elevation Models (PaleoDEMS) for the Phanerozoic
- DOI：[10.5281/zenodo.5460860](https://doi.org/10.5281/zenodo.5460860)
- 作者：Christopher R. Scotese、Nicky Wright
- 许可：CC BY 4.0
- 高分辨率包：`Scotese_Wright_2018_Maps_1-88_6minX6min_PaleoDEMS_nc.zip`
- 包 MD5：`89eb50d8645707ab221b023078535bda`

Zenodo 页面和报告描述了 117 个模型；本次实际下载的高分辨率包中有 **109 个** NetCDF 文件，年代严格为 `0, 5, 10, …, 540 Ma`。本文采用实际文件统计，不把报告中的 117 当作当前包的时间片数。

每个实测文件：

- `z` 数组为 `1801 × 3601`。
- 纬度、经度名义范围分别为 `-90–90°`、`-180–180°`。
- 单位为米。
- 高度量化步长为 40 m；正式海陆规则采用 `z > 0 m`。

文件的纬度坐标变量为升序，但数组第 0 行实际需要解释为北端。0 Ma 对 Natural Earth 的验证结果为：第 0 行解释为北端时 IoU 为 `0.9389`，按坐标变量直接翻转时仅为 `0.1352`。验证工具据此采用北端在前的数组顺序。

### 3.2 原始制作口径

[Scotese & Wright 2018 报告](https://zenodo.org/records/5460860/files/Scotese_Wright2018_PALEOMAP_PaleoDEMs.pdf)说明其制作过程：

- 以现代全球地形和海深为底图，把网格随 PALEOMAP 板块模型旋转到古位置。
- 结合岩相、沉积环境、构造历史和现代类比进行人工解释与修改。
- 古洋底按洋壳年龄—水深关系恢复；古山地、裂谷等也会使用现代地貌作为类比进行编辑。
- 报告明确称这些数据是“first draft”，列出了年轻地形残留、山高可能偏大、古生代海盆简化等已知问题。

所以它是有地质依据的解释型产品，不是随机噪声；但其高空间采样不等于同尺度的观测约束，并且整套结果绑定 PALEOMAP 自己的板块重建。

### 3.3 与当前数据的比较方法

验证脚本为 `Tools/validate_paleodem.py`：

1. 从压缩包读取指定年代的高程网格。
2. 使用 `z > 0 m` 得到 PaleoDEM 陆地掩膜。
3. 用项目现有 `draw_reconstruction()` 在相同年代生成 MULLER2022 陆地掩膜。
4. 统一到 `2048 × 1024` 等经纬网格。
5. 按纬度余弦计算球面面积权重，输出 IoU、全球不一致面积和双方独有陆地面积。
6. 在 1° 诊断网格上搜索最佳纯经度平移，检查问题是否只是中央经线不同。

复现命令：

```bash
uv run python Tools/validate_paleodem.py \
  --paleodem-zip .local/research/paleodem/Scotese_Wright_2018_Maps_1-88_6minX6min_PaleoDEMS_nc.zip \
  --out-dir .local/research/paleodem/comparison
```

输出位于 `.local/research/paleodem/comparison`，不进入 Git。

### 3.4 实测结果

| 年代 | 与 MULLER2022 IoU | 全球面积不一致 | PaleoDEM 陆地占比 | MULLER2022 陆地占比 | 最佳纯经度平移后 IoU |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 Ma | 0.9383 | 1.79% | 27.56% | 28.78% | 0.9363（0°） |
| 100 Ma | 0.4790 | 19.32% | 26.91% | 27.93% | 0.5503（+10°） |
| 250 Ma | 0.5890 | 14.42% | 28.65% | 27.10% | 0.5904（+2°） |
| 400 Ma | 0.2503 | 24.80% | 15.95% | 25.40% | 0.3745（−41°） |
| 540 Ma | 0.1893 | 26.59% | 18.32% | 20.68% | 0.3217（−71°） |

0 Ma 的额外交叉验证：PaleoDEM 与 Natural Earth 10m land 的 IoU 为 `0.9389`，全球面积不一致为 `1.79%`。这说明 NetCDF 的经度、行顺序和海陆阈值已经正确解码，古地球的低匹配度不是简单的文件读错。

最佳纯经度平移只能有限改善古地球结果，无法把 100–540 Ma 恢复到现代级别的一致度。对比图也显示偏差并非只发生在海岸的几个像素，而是包含大陆整体位置、相对拼合和淹没范围的差异。

### 3.5 使用判断

不能直接执行以下做法：

- 在 MULLER2022 陆地 Mesh 上按同一经纬度采样 PaleoDEM 高度。
- 用 PaleoDEM 的 `z = 0` 轮廓替换当前 MULLER2022 海岸线。
- 用非刚性图像配准把两套古大陆强行拉齐，再把结果称作可验证古地形。

这些做法会在错位处把海深采到陆地、把山脉放到错误板块，或引入没有地质依据的形变。

PaleoDEM 当前可以用于：

- 确定黄—棕高程色带和蓝色海深色带的视觉范围。
- 研究典型年代中山地、低地、大陆架和海盆的总体比例。
- 作为未来 MULLER2022 推演结果的独立对照组，而不是直接输入。

## 4. 基于公开方法自行推演

### 4.1 最接近当前目标的方法

[Merdith et al. 2025，Where were the mountains and how big were they?](https://doi.org/10.31223/X54T9B)提出了参数化、可复现的全球推演方法：

- 使用覆盖 `1000–0 Ma` 的全板块模型 MER21。
- 在大陆—海洋边界内建立带板块 ID 和有效年代的等面积节点。
- 从动态板块边界识别大陆弧、大陆碰撞、裂谷，并叠加大火成岩省。
- 每 `1 Ma` 前向迭代地形生长和侵蚀；侵蚀取节点及 21 个近邻的局部起伏，并修改 Montgomery & Brandon 2002 曲线以适配百万年时间步。
- 在 0.1° 网格插值，再以 1° 高斯滤波输出。
- 用合成洋壳年龄网格和 GDH1 年龄—水深关系推算海盆。
- 使用现代 ETOPO 海岸高程分布构造大陆架/沿海过渡，并用古生物与沉积记录约束海侵。

论文输出 `970–0 Ma`、每 `1 Ma`、默认 1°。作者明确说明目标是恢复山地的大尺度位置和等级，不是重建现代地形那样的山峰、河谷细节。

### 4.2 与当前 MULLER2022 的匹配度

当前数据包自身的 README 明确写明：MULLER2022 与 Merdith et al. 2021 在相对板块运动和板块拓扑上“very similar”，但包含后续更新和修复。本项目还使用纯古地磁参考系 `Rotations/1000_0_rotfile.rot`，适合古地理和气候分析。

因此算法层面高度兼容，但不能把论文基于 MER21 的输出当成当前 MULLER2022 的精确结果。正确方式是在当前 MULLER2022 的大陆范围、拓扑和旋转上重新运行。

### 4.3 输入缺口与实现难度

当前 MULLER2022 已包含大陆/COB、板块拓扑、汇聚/离散边界和旋转模型，足以支撑大陆节点与大部分构造环境识别。仍需补齐：

- 论文所用大火成岩省数据库及其数据映射。
- 合成洋壳年龄网格生成流程。
- 显生宙海侵约束和新元古代沉积约束。
- 论文补充材料中的完整方程、参数表和代码。

可行性分级：

| 范围 | 可行性 | 说明 |
| --- | --- | --- |
| 大陆大尺度高程：山地/高原/低地 | 中等偏高 | 当前板块输入大体具备；取得补充代码后风险明显下降 |
| 裂谷与大陆碰撞随时间生长/侵蚀 | 中等 | 需要复现事件识别和参数化迭代，并做现代回放校验 |
| 全球古海盆深度 | 中等偏低 | 合成洋壳年龄是独立的大模块，早期海洋约束弱 |
| 大陆架、海侵和内陆浅海 | 中等偏低 | 依赖 PBDB/沉积数据和海平面口径 |
| 10 km 尺度的真实山谷、河网、海沟 | 当前不可验证 | 公开方法本身不声称提供这种精度 |

如果无法取得原代码，从论文重写大陆高程核心是可行的，但不是短脚本：需要一个可单独验证的离线科学计算模块。海盆年龄和海侵应拆成后续阶段，不能与第一版混在一起。

## 5. 当前决策与下一步

当前决策：

1. 不把 PALEOMAP PaleoDEM 接入 Unity 正式运行时。
2. 保留验证工具和量化基线，以后任何古地形候选都必须跑同类比较。
3. 继续寻找或向作者获取 Merdith 2025 补充代码、参数和输出；当前不声称原型等同于论文完整结果。
4. 大陆大尺度高程原型已经实现，处理大陆弧、碰撞、裂谷、生长与侵蚀，并以 MULLER2022 海岸线强制裁切海陆。实现和实测见[古地形推演原型与交叉验证](paleotopography-prototype.md)。
5. 古海盆、海侵、LIP 和裂谷肩隆升仍未实现，后续独立评估。
6. Unity 表现继续保持简单：不做高度夸张，高程仅用于颜色与可关闭的 Hillshade。

该路线不会把解释型结果伪装成测量真值。最终高度场应带有来源、模型版本、参数和不确定性等级，供游戏规则选择不同可信度或不同情景。
