# 古地形推演原型

## 1. 当前状态

`Tools/prototype_paleotopography.py` 是一个可完整运行的大陆大尺度古高程原型。它使用 MULLER2022 的板块旋转和构造边界，从 `970 Ma` 逐 `1 Ma` 前向推演到现代，并输出指定年代的规则高度网格和预览图。

当前目标是为游戏提供大致合理、无明显坐标或数值错误的山地/高原/低地分布，不把结果描述为科学上唯一正确的古地形。

暂未接入 Unity。所有推演结果写入 `.local`，属于可重建验证产物。

## 2. 输入

原型只使用项目已经固定版本的 MULLER2022 v1.2.4：

- `Rotations/1000_0_rotfile.rot`：纯古地磁参考系板块旋转。
- `StaticPolygons/shapes_static_polygons_Merdith_etal.gpml`：给大陆节点分配板块 ID。
- `Coastlines/shapes_coastlines_Merdith_etal.gpmlz`：每个年代最终海陆裁切。
- `Topologies/250-0_plate_bounds.gpml`。
- `Topologies/410-250_plate_bounds.gpml`。
- `Topologies/1000-410-Convergence.gpml`。
- `Topologies/1000-410-Divergence.gpml`。

PALEOMAP PaleoDEM 的 0 Ma 网格仅用于现代高程分布校准和交叉验证，不向古地球搬运任何现代山脉坐标。古年代 PALEOMAP 与 MULLER2022 的空间位置不一致，因此不进行逐像素混合。

## 3. 算法

### 3.1 大陆节点

在单位球上生成 `12000` 个 Fibonacci 近似等面积候选节点，以 MULLER2022 0 Ma 海岸线选择现代露出陆地，再用静态板块多边形分配 plate ID。

实测得到：

- 现代陆地候选节点：`3483`。
- 成功分配板块的节点：`3483`。
- 未分配节点：`0`。
- 涉及 plate ID：`298`。

每个节点保留自身高程、弧事件记忆、碰撞计时器和裂谷计时器。每个年代都用 MULLER2022 RotationModel 把节点从现代坐标重建到当时位置，而不是让高度固定在经纬网格上。

### 3.2 构造环境

方法参考 Merdith et al. 2025：

- 大陆弧：节点距俯冲边界小于 `450 km`。
- 大陆碰撞：最近 10 Ma 曾处于大陆弧、当前已离开弧环境、距另一 plate ID 小于 `500 km`，且距离正在减小。触发后持续 `40 Ma`。
- 裂谷：真实 `ContinentalRift` 使用 `400 km` 范围；`MidOceanRidge` 只作为早期模型缺少裂谷线时的代理，收紧到 `150 km`。触发后向 `-200 m` 线性沉降，最长 `40 Ma`。
- LIP：当前没有接入公开 LIP 数据库，暂不模拟。

碰撞和裂谷判据比论文的完整多条件方法简单，属于原型的主要不确定性来源。

### 3.3 生长和侵蚀

构造生长沿用论文参数：

```text
growth = scale / exp(elevation × decay)
arc:       scale=300, decay=0.001
collision: scale=700, decay=0.0003
```

侵蚀使用节点及其 21 个最近邻的中值高程计算局部起伏：

```text
erosion = 301 - 200 × atan((2000 - local_relief) × 0.007)
```

论文 PDF 的方程表漏排了 `atan` 前的负号；Figure 13 的公式和曲线包含负号。若没有该负号，平坦低地会以约 `600 m/Ma` 消失，方向与图中曲线相反。代码按 Figure 13 修正，并有单元测试锁定侵蚀随局部起伏单调增大。

简化模型还增加 `0.3%/Ma` 的非活动高地松弛。原因是只依赖局部起伏时，宽而平的远古高原永远不会降低；实测曾在现代撒哈拉留下约 4.6 km 的假高原。加入松弛后撒哈拉预测 P90 从约 `2686 m` 降到 `852 m`，现代参考为 `800 m`。活动弧、碰撞区和裂谷不应用该松弛。

### 3.4 网格化和高程尺度

输出时使用球面上 4 个最近节点做反距离平方插值，再以当前年代 MULLER2022 海岸线强制裁切：

- 陆地不会输出负高程。
- 海洋暂时统一为 `-4000 m`，只用于预览，不是推演海深。
- 不改变 MULLER2022 海岸线。

论文使用现代 ETOPO 校准海岸和高程分布。本原型采用更简单的一维分位映射：把 0 Ma 模型高程分布映射到 PaleoDEM 0 Ma 分布，并把同一条单调映射用于所有年代。该步骤只改变高度尺度，不改变任何山脉位置和空间排序。

## 4. 交叉验证

### 4.1 数值与坐标

对 `0、50、100、160、200、250、400、540、750、970 Ma` 的检查全部通过：

- 所有高程均为有限数，没有 NaN 或 Infinity。
- 原始节点高程保持在配置的 `-500–7000 m` 范围内。
- 板块旋转后的最大单位球长度误差约 `2.22e-16`。
- NumPy 旋转矩阵与 pyGPlates 对多个 plate ID、多个年代的结果误差小于 `1e-12`。
- 所有输出的陆地负值格数为 `0`。
- 所有输出的海洋非 `-4000 m` 格数为 `0`。

### 4.2 现代空间分布

以 PaleoDEM 0 Ma 为现代高程参照，在 `3260` 个有效大陆节点上验证：

| 指标 | 原型 | 随机置换基线 |
| --- | ---: | ---: |
| Spearman 空间秩相关 | `0.1415` | `-0.0009 ± 0.0153` |
| `>=1000 m` 高地 F1 | `0.3704` | `0.2099 ± 0.0135` |

相关性不高，说明它不能替代真实现代 DEM；但明显高于保持相同高程分布的随机位置，证明构造边界产生了可辨认的空间信号，而不是随机噪声。

### 4.3 代表区域

| 区域 | 原型 P90 | 现代参考 P90 | 判断 |
| --- | ---: | ---: | --- |
| 喜马拉雅 | `1996 m` | `5100 m` | 位置可辨，高度低估 |
| 安第斯 | `2223 m` | `3630 m` | 位置可辨，高度低估 |
| 落基山 | `1661 m` | `2040 m` | 大致合理 |
| 澳大利亚内陆 | `531 m` | `560 m` | 接近 |
| 撒哈拉 | `715 m` | `800 m` | 修正后接近 |
| 东非裂谷 | `584 m` | `1520 m` | 明显低估；裂谷原型只模拟沉降，缺少裂谷肩隆升 |

当前最明显的剩余系统偏差是活动造山带高度不足、裂谷肩隆升缺失，以及深时部分年代高地面积偏大。它们属于模型范围不足，而不是坐标翻转、年代方向错误或数值爆炸。

## 5. 运行和产物

完整推演：

```bash
uv run python Tools/prototype_paleotopography.py \
  --out-dir .local/research/paleotopography-prototype \
  --modern-reference-netcdf \
  .local/research/paleodem/Scotese_Wright_2018_Maps_1-88_6minX6min_PaleoDEMS_nc.zip
```

单元测试：

```bash
uv run python -m unittest discover -s Tools/tests -p 'test_*.py' -v
```

输出：

- `report.json`：参数、逐年代轨迹、数值检查和现代交叉验证。
- `topography_XXXXMa.npz`：`720 × 360` float32 高程和海陆掩膜。
- `topography_XXXXMa.png`：黄—棕色预览图。

下一阶段如接入 Unity，应先把脚本扩展为可生成全部 `1 Ma` 网格，并单独设计分块压缩和运行时读取；当前原型不应直接作为最终科学数据发布。
