# 希克苏鲁伯撞击事件层

时间轴在正式 **66 Ma** 帧停留时，单次播放 75 秒撞击演示，结束后保留坑体和缓慢漂移的全球烟尘。拖动经过该年代不触发；离开、拖动或关闭时立即复位。首次进入平滑转向球缘近景；后半场拉远展示全球。玩家手动操作会立即终止镜头编排。

## 操作与结构

- 界面左上角“事件动画”控制总开关，“进入／退出动画视角”切换近景演出和进入前视角。“重新播放”清空灾后效果并从零演出；“烟尘层”可单独隐藏云层以观察保留的坑体。
- 禁用场景的 `EarthEventLayer` 根节点可关闭整层；Inspector 中也可调整 `Events Enabled`。
- `Assets/EarthEvents/Data/Chicxulub.asset` 集中保存科学基准、显示倍率和分镜曲线。
- `ImpactSequencePlayer.Play()` 启动，`Replay()` 清空后重播，`StopAndReset()` 清理，`Evaluate(seconds)` 直接预览任意阶段。预览时设置 `AutomaticAdvance=false`；`Advance(seconds)` 可用于确定性推进。
- 预制体、Shader、材质、配置、运行时脚本和专项验收都在 `Assets/EarthEvents/`。
- 场景构建器发布通用 `SceneCreated` 事件，模块自行订阅并安装；不依赖模块具体类型。删除模块不会阻断基础场景构建。

地球控制器仅提供 `CurrentTimelineState / TimelineStateChanged`、`ViewManipulated` 和附加 UI 命中区域。事件层通过适配器订阅，不参与古地理、地形或气候数据的加载。

所有视觉资源在首次播放时分配，后续重播复用。粒子按固定种子和绝对展示时间求值，不进行依赖历史帧的累积模拟。动画坐标以地球半径为单位，通过地球子节点跟随旋转、位移和缩放。

坑体使用独立球面局部网格。基础海陆 Shader 的通用 `SurfacePatch.cginc` 提供默认关闭的局部替换接口；事件层用 `MaterialPropertyBlock` 只控制 `_SurfacePatch` 和 `_SurfacePatchVisibility`。退出时恢复这两项，不覆盖其他系统属性，不修改原始网格或高度数据。

## 科学事实、模型估计与艺术处理

| 项目 | 采用口径 |
| --- | --- |
| 年代 | 约66 Ma；依据 [LPI](https://www.lpi.usra.edu/science/kring/Chicxulub/) |
| 现代坑中心 | 21.30°N、89.54°W；依据 [Gulick等，2013](https://doi.org/10.1002/rog.20007) |
| 小行星尺寸 | 估计直径10–15 km，基准取12 km；依据 [LPI](https://www.lpi.usra.edu/features/chicxulub/) |
| 最终坑径 | 约180–200 km，基准取180 km；依据 [Gulick等，2013](https://doi.org/10.1002/rog.20007) |
| 速度与轨迹 | 20 km/s、相对水平面60°、东北向西南。属于复原参数，非确定观测；依据 [Collins等，2020](https://doi.org/10.1038/s41467-020-15269-x) |
| 环境 | 被海水覆盖的大陆架，呈现水汽、岩石喷出物和回涌；依据 [Gulick等，2019](https://doi.org/10.1073/pnas.1909479116) |

现代点位由工程 MULLER2022 v1.2.4 静态板块归属和旋转模型重建至66 Ma：板块205（Yucatan, Central America），古坐标约24.95932°N、62.17533°W。它不在该帧的露出陆地多边形内。该结论来自工程数据，不等于精确测量的古经纬度或局部水深。

重建命令（使用现有锁定版本依赖）：

```sh
uv run python Tools/build_impact_site.py
```

输出 `Assets/EarthEvents/Data/chicxulub-site.json`，包含模型、板块、Feature ID、坐标变换及输入文件SHA-256。展示坐标为数据坐标的 `(x, -y, z)`。

艺术默认值：实体直径×6、坑径×2.5、光晕直径0.10R、尾流最长0.75R、羽流最高0.20R、顶部宽约0.30R。科学值与倍率单独存储。75秒是分段变速的演示，不代表真实过程只持续75秒。岩石坑的纵向比例、烟云形态、水波外观也属于展示性复原。

蘑菇形来自膨胀翻卷的蒸汽与碎屑羽流，不使用核武器模板。波前沿球面传播；水波比大气波慢。当前仅演示近场水波，未实现依据海底地形传播的全球海啸模拟。结束后坑体与烟尘保持，不自动恢复地球。坑缘、坍塌块与峰环加入多尺度不规则变化；总体仍近圆形。

全球遮蔽参考 [Senel等，2023](https://www.nature.com/articles/s41561-023-01290-4)：基于沉积约束的模型估计，细硅酸盐粉尘可在大气中滞留约15年，光合作用可能停滞近2年；烟炱与硫气溶胶也有贡献。这些时间是模型估计。两层球面烟尘、厚重褐灰云团及18–60秒的全球扩散是艺术化表达，不是大气输运模拟，也不表示真实烟云几十秒内到达全球。

## 75秒分镜

| 时间 | 行为 |
| --- | --- |
| 0–3秒 | 斜向接近；首次进入的前2秒平滑定位 |
| 3–6秒 | 大气前缘白热、渐强长尾流 |
| 6–7秒 | 局部闪光、火球和初始波前 |
| 7–12秒 | 弹道喷出物、坑穴开挖、坍塌和峰环 |
| 9–25秒 | 更大的蘑菇状羽流上升、扩张和翻卷 |
| 18–35秒 | 海水回涌、余烟与高空烟尘衔接，坑形保留 |
| 32–60秒 | 镜头缓慢拉远，烟尘从撞击区沿球面扩散至全球 |
| 60–75秒 | 浓厚烟尘遮蔽天空，结束后保持缓慢漂移 |

## 验收

Unity菜单 `Earth Demo > Events > Install Impact Layer` 安装到当前演示场景。完整构建场景时也会自动安装。

`Earth Demo > Events > Validate and Record Impact` 运行触发、幂等、拖动、开关、根节点禁用、材质属性还原、坐标、单次结束保持、重播复位、镜头切换、资源复用和确定性验收，并输出1080p关键帧与75秒/30fps录像（chicxulub-aftermath.mp4）。录像使用本机已安装的 `/opt/homebrew/bin/ffmpeg`，不是运行时依赖。

结果位于 `.local/validation/impact/`，不纳入版本管理。专项测试后继续运行既有 `Earth Demo > Run Play Validation` 检查地球与时间轴回归。
