# 古海深推演原型

## 1. 当前状态

`Tools/prototype_paleobathymetry.py` 在 MULLER2022 v1.2.4 上从 `970 Ma` 逐 `1 Ma` 推演合成洋壳年龄，并按 GDH1 年龄—水深关系生成大尺度古海深。它读取已有大陆高程原型，将两者合并为统一的有符号高度场。

当前原始产物用于离线算法和视觉验证，写入 `.local/research/paleobathymetry-prototype`；完整帧经 `Tools/build_runtime_terrain.py` 编译后接入 Unity 运行时。

## 2. 数据口径

每个年代先分成三个互斥区域：

1. 露出陆地：`Coastlines/shapes_coastlines_Merdith_etal.gpmlz`。
2. 水下大陆地壳：`COB_Coasts/COB_polygons_and_coastlines_combined_1000_0_Merdith_etal.gpml` 减去露出陆地。
3. 真正洋壳：其余海域。

水下大陆地壳直接定义为 `-160 m` 浅海，不生成洋壳年龄。该值是项目的视觉分类参数，不是 MULLER2022 自带测深值。真正洋壳才进入年龄平流和 GDH1 计算。所有年代使用同一规则，没有现代专用分支。

### 2.1 MULLER2022 现有高度/深度信息盘点

| 数据 | 可直接提供的信息 | 当前用途 |
| --- | --- | --- |
| Coastlines | 当时露出陆地多边形 | 海陆边界 |
| COB_Coasts | 大陆—洋壳边界内的大陆地壳范围 | 识别水下大陆地壳并定义浅海 |
| 动态 Topologies | 封闭板块、plate ID、洋中脊、俯冲和转换边界 | 洋壳平流、生成和消亡 |
| Basin 等分类多边形 | 地质单元类型和名称 | 没有深度值，当前不参与定量海深 |
| Cratons / Continents / StaticPolygons | 大陆、克拉通和静态板块分类 | 大陆推演与 plate ID 分配 |
| 少数 `subductionZoneDepth` | 俯冲板片深度元数据 | 不是海沟水深，且仅少数边界有值，不用于渲染 |

数据包没有全球逐格高程、测深、海底年龄、海山高度或等深线。因此能直接使用的几何分类优先使用，其余海盆深度仍需推演。

## 3. 洋壳年龄推演

### 3.1 动态板块网格

每个年代用全部拓扑文件解析 `ResolvedTopologicalBoundary`。plate ID 栅格采用球面点在多边形测试，而不是直接把球面多边形画到等经纬平面；后者会把跨日期变更线或大于半球的板块错误画成补集。

在 `0、540、970 Ma` 的抽样测试中，全球每个格点都能落入一个动态拓扑多边形。逐百万年完整运行允许修补小于全球网格 `0.5%` 的拓扑离散缝隙：缝隙格点取球面最近的已解析 plate ID，并把补点数写入报告；超过阈值则中止，不掩盖大范围拓扑故障。完整实测有 74 个年代需要补点，最大发生在 `121 Ma`，为 `53/64800`，约 `0.082%`。

### 3.2 年龄平流

推演从 `970 Ma` 前进到 `0 Ma`。对年轻年代的每个 plate ID，使用：

```text
R_stage = R_older × inverse(R_younger)
```

把年轻年代格点反推到上一年代位置并采样旧年龄。只有源位置仍属于同一 plate ID 且原来是真正洋壳时才保留，随后年龄增加 `1 Ma`。这使洋壳随板块移动，并让跨越板块边界、进入陆地或水下大陆地壳的旧洋壳失效。

洋中脊 `140 km` 内年龄重置为 `0 Ma`。最老年代以及无法从上一年代采到历史的海洋格点，按以下明确近似初始化：

```text
age = distance_to_mid_ocean_ridge / 30 km/Ma
```

年龄裁切到 `0–220 Ma`。固定 `30 km/Ma` 是半扩张速率的原型参数，只补拓扑切换和初始状态造成的缺口，不覆盖成功平流的年龄。

## 4. 年龄转海深

真正洋壳使用 Stein & Stein 1992 的 GDH1：

```text
age <= 20 Ma: depth = -(2600 + 365 × sqrt(age))
age >  20 Ma: depth = -(5651 - 2473 × exp(-0.0278 × age))
```

单位为米，负值向下。最终做 `0.65` 个网格单元的高斯平滑，再重新应用海陆掩膜。露出陆地从大陆高程原型读取，合并后的统一数据仍遵守：正值为陆地海拔，负值为海深，海陆分类由 MULLER2022 几何决定。

## 5. 交叉验证

完整 `970–0 Ma`、逐 `1 Ma`、`360 × 180` 工作网格已运行通过：

- 十个代表年代的真正洋壳年龄均有限且位于 `0–220 Ma`。
- 水下大陆地壳和陆地不含洋壳年龄。
- 所有海洋高程为负，所有陆地海深为 NaN。
- 代表年代洋中脊中位深度为约 `-2.66` 至 `-2.74 km`；80 Ma 以上老洋壳为约 `-5.39` 至 `-5.57 km`，冷热洋壳方向正确。
- 0 Ma 对 PaleoDEM 的海深 Spearman 空间秩相关为 `0.6329`，随机置换为 `-0.0007 ± 0.0047`。
- 0 Ma 的 `<= -4000 m` 深海 F1 为 `0.7680`，随机置换为 `0.5342 ± 0.0022`。

0 Ma 主要海盆中位深度对比：

| 海盆 | 原型 | PaleoDEM 参考 |
| --- | ---: | ---: |
| 太平洋 | `-4495 m` | `-4320 m` |
| 大西洋 | `-4441 m` | `-4120 m` |
| 印度洋 | `-4710 m` | `-3960 m` |

空间分布明显优于随机基线，但整体海盆偏深，特别是印度洋。COB 浅海按用户确认的游戏口径直接分类，因此浅海面积与真实大陆架测深不完全等价。

## 6. 已知边界

- 没有海沟、海山、海底高原、LIP、沉积物和动态地形。
- COB 水下大陆地壳统一为浅海，只表达分类，不表达真实大陆坡剖面。
- 深时洋中脊和板块拓扑不确定性会直接传递到海底年龄与海深。
- 深时 plate ID 重组年代会出现一次性补建峰值，最高约 83%；相邻普通年代通常恢复到 96%–98% 的历史平流。
- `1°` 最近邻平流会在板块边界附近产生离散误差。
- 现代 PaleoDEM 只用于交叉验证，不参与推演，也不把现代海盆位置复制到古代。

## 7. 运行与产物

```bash
uv run python Tools/prototype_paleobathymetry.py \
  --out-dir .local/research/paleobathymetry-prototype \
  --modern-reference-netcdf \
  .local/research/paleodem/Scotese_Wright_2018_Maps_1-88_6minX6min_PaleoDEMS_nc.zip
```

每个代表年代输出：

- `paleobathymetry_XXXXMa.npz`：洋壳年龄、海深、plate ID、陆地和 COB 浅海掩膜。
- `paleobathymetry_XXXXMa.png`：海深预览。
- `terrain_XXXXMa.npz`：合并后的全球有符号高度场。
- `terrain_XXXXMa.png`：陆地与海洋合并预览。
- `report.json`：参数、每百万年平流统计、数值检查和 0 Ma 交叉验证。
