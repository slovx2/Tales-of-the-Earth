# 地形与海深渲染设计

## 1. 当前目标

下一阶段在不改变现有海岸线几何口径的前提下，提高海洋和陆地的地形表现：

- 海洋根据水深使用由浅到深的蓝色色带。
- 陆地根据海拔使用黄色、赭色、棕色至灰白色的高程色带。
- 陆地叠加由高程梯度计算的地形晕渲，突出山脉、盆地和坡向。
- 海陆边界仍由每个年代的 MULLER2022 海岸线网格决定。

本阶段不做几何高度夸张，不通过顶点位移改变地球轮廓。

## 2. 渲染方法

### 2.1 陆地

陆地继续使用现有的逐年代动态 Mesh。高程数据只作为 Shader 属性参与像素着色，不写入 Mesh 顶点。

陆地颜色由两部分组成：

1. 高程色带：以海拔值查询可配置的一维颜色表。
2. 地形晕渲：从高度场邻域计算梯度，并结合固定光照方向得到明暗变化。

第一版使用偏地质地图风格的色带：

| 高程范围 | 颜色方向 |
| --- | --- |
| 海平面附近 | 浅沙黄、米黄 |
| 低地 | 金黄、赭黄 |
| 中高地 | 黄棕、土棕 |
| 高地 | 深棕、暗褐 |
| 极高地 | 灰棕至灰白 |

高程色带和晕渲强度必须独立配置，避免把光照明暗烘焙进基础颜色。

### 2.2 海洋

海洋继续使用独立的球体表面。海底不生成可见几何，水深只用于地图式着色。

水深色带重点区分以下区域：

| 水深范围 | 表现重点 |
| --- | --- |
| 0–200 m | 浅海和大陆架 |
| 200–1000 m | 大陆坡上部 |
| 1000–4000 m | 普通海盆 |
| 4000–6000 m | 深海平原 |
| 6000 m 以下 | 海沟 |

海面可保留弱高光和弱 Fresnel 反射，但不能盖过海深颜色。

## 3. 数据口径

高度场统一使用以米为单位的有符号值：

- 正值表示陆地海拔。
- 负值表示海洋水深。
- 零值表示海平面。

海陆分类不由高度场决定，而由 MULLER2022 当前年代的陆地几何决定。外部地形数据与 MULLER2022 海岸线存在偏差时，必须先评估偏差，不能直接用外部数据替换当前海岸线。

现代地球候选数据为 GEBCO 或 ETOPO。古地球高程与海深数据尚未确定。PALEOMAP PaleoDEM 的实测表明它在古地球年代不能直接与 MULLER2022 叠加；量化结果和推演候选见[古地形数据验证与推演可行性](paleotopography-data-research.md)。

在数据来源确定前，不使用纯随机噪声或没有公开方法依据的程序地形作为正式古地形。

当前不把任何外部古高程数据接入正式运行时。后续若自行推演，高程必须从当前 MULLER2022 的板块拓扑和可追溯的公开算法生成，并保留来源、参数和验证结果。

目前已有一个尚未接入 Unity 的[古地形推演原型](paleotopography-prototype.md)。它只验证大陆大尺度高程路线，海洋深度仍为占位值。

## 4. 当前技术边界

- 保留当前动态陆地 Mesh 和每年代独立海岸线几何。
- 不加密全部年代的 Mesh 来保存地形细节。
- 不迁移到静态 Cube Sphere。
- 不做 GPU Tessellation。
- 不做顶点位移和高度夸张。
- 不预烘焙每个年代的最终 RGB 地球纹理。

如果后续确定需要真实几何起伏，再单独评估共享高密度球面、分块 LOD 或其他地形网格方案。

## 5. 验收标准

第一版地形渲染需要满足：

- 0 Ma 的主要山系、高原、深海盆地和海沟位置可辨认。
- 陆地轮廓仍与当前 MULLER2022 0 Ma 输出一致。
- 色带、晕渲和海面反射可以独立调整。
- 关闭晕渲后仍能仅凭颜色读取大尺度高程和海深。
- 拖动时间轴时不因高度纹理读取产生明显卡顿。
