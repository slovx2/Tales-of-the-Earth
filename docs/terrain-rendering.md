# 地表与海深渲染设计

## 1. 当前目标

地球采用自然色卫星地图风格，让陆地在没有现代专用贴图的情况下仍能直观呈现森林、草地、旱地、沙漠、岩石和冰雪。渲染首先服务于古大陆演化的可读性和游戏画面，不把程序生成的颜色解释为真实古气候或真实古地形。

当前约束：

- 海陆轮廓由每个年代的 MULLER2022 动态陆地几何决定。
- 陆地不做顶点位移或高度夸张，地球外轮廓保持球形。
- 不使用只适用于 0 Ma 的现代卫星贴图，所有年代沿用同一套表现口径。
- 原型 NPZ 不直接放入 Unity；经 `build_runtime_terrain.py` 编译后的高度场帧文件已接入运行时 Shader。

## 2. 当前运行时渲染

### 2.1 陆地自然色

`Earth/DynamicLand` 的大陆级生物群系完全由 `DynamicClimateRenderer` 上传的
Pohl/FOAM 连续气候变量和 Köppen 主/次类别决定。类别边界参数在同一材质内混合，
不再使用纬度带、随机湿润度或大陆级 FBM 来决定森林/沙漠分布。

Shader 只保留三类视觉修正：MULLER2022 当前海陆几何、古地形高度对裸岩/积雪的
辅助权重，以及不改变生物群系类别的小尺度 FBM 明暗扰动。气候帧不可用时明确回退
中性陆地色，而不是伪造一个旧的程序气候场。

### 2.2 海洋

海洋使用独立球体和 `Earth/DynamicOcean`：

- 当前深浅蓝变化是基础视觉渐变，不代表真实水深。
- 保留弱镜面反射和少量环境光，避免高光遮挡陆地。
- 海洋球体位于陆地动态网格下方，陆地通过 `_SurfaceOffset` 略微抬升以减少闪烁。

古海深原型已经能生成 `970–0 Ma` 的逐 `1 Ma` 有符号高度场。`Tools/build_runtime_terrain.py` 将合并场压缩为单个半精度帧文件；Unity 只把当前帧上传到复用的 `RHalf Texture2D`。

### 2.3 大气层

大气层使用稍大的透明背面球体，通过 Fresnel 风格边缘光提供蓝色轮廓。它不参与海陆分类，也不承载云层数据。

## 3. 数据与视觉的职责边界

当前各层职责如下：

| 内容 | 当前来源 | 是否具有数据含义 |
| --- | --- | --- |
| 海陆轮廓 | MULLER2022 Coastlines 动态几何 | 是 |
| 年代与板块位置 | MULLER2022 重建结果 | 是 |
| 森林、草地、沙漠色块 | Pohl/FOAM → Köppen 气候帧 | 古气候代理 |
| 岩石和伪高地细节 | 球面程序噪声 | 否，仅用于视觉 |
| 当前海洋深浅蓝 | Shader 基础渐变 | 否，仅用于视觉 |
| 古陆地高度 | 离线推演原型，经运行时帧文件读取 | 有近似数据含义，驱动陆地颜色 |
| 古海洋深度 | COB、洋壳年龄和 GDH1 推演原型，经运行时帧文件读取 | 有近似数据含义，驱动海洋色带 |

海陆分类始终由 MULLER2022 当前年代的陆地几何决定，不由视觉纹理或高度场反向决定。

## 4. 后续接入地形与海深

当前运行时已经把离线有符号高度场转换为可流式读取的球面栅格，并在 Shader 中参与着色。后续可继续提高数据质量：

1. 陆地高程调节岩石、积雪、植被上限和地形晕渲。
2. 海洋水深驱动大陆架、大陆坡、海盆和海沟的多级蓝色色带。
3. 高度只用于像素着色，第一版仍不改变球面顶点位置。
4. 程序纹理继续补足小尺度外观，但真实高度场优先决定地貌位置。

原型方法、参数和验证结果见[古地形推演原型](paleotopography-prototype.md)与[古海深推演原型](paleobathymetry-prototype.md)。

## 5. 当前验收标准

- 所有年代使用同一自然色渲染口径，不对 0 Ma 做现代贴图特判。
- 球面程序纹理没有明显经纬度接缝。
- 森林、旱地、沙漠和极区冰雪由气候类别驱动并连续过渡；无气候帧时显示中性大陆。
- 海面高光不遮挡主要陆地轮廓。
- Shader 改动不影响逐 `1 Ma` 时间轴拖动和动态 Mesh 切帧性能。
- 重置视角后地理北极投影方向为屏幕正上方。
- 视觉生成内容在文档和代码中不得表述为真实古气候或真实古地形。
